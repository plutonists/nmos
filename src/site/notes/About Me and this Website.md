## What's this website?
Good question (not really)! This website is a personal stash of interests; movies, literature, software, videos, art, photos, you name it. I've been wanting to make a personal corner of mine on the internet so I can ~~<font color="#ec2e37">MARK MY TERRITORY</font>~~ have a place I can truly call home 🏠.

Home can mean a lot of things; a place where you can find comfort, a place where you can feel freely expressive, and do whatever you want! This is my corner, and pretty much anyone is welcome! In fact, let me [break it down for you](https://i.clouds.tf/siop/p5hs.gif).

*"What if whatever you list is malicious?"*
Use an adblocker, because most malicious things you'll find are caused by ads. Plus, because I'm not a security geek, I'd be posting it on FMHY's Discord server for checking if I'm skeptical about listing it (I'd use online sandboxes like [Triage](https://tria.ge) to test, but if I'm still REALLY skeptical, I'd double-check). I would do this with websites that host software, but otherwise, probably not. **You can't get compromised by a website if you have:**

1. **Common Sense:** If you see "DOWNLOAD NOW!!!!" or anything that doesn't quite fit with the website's UI, then obviously don't click it. If you find something downloading all of a sudden, *obviously* don't open it, just delete it and you'll be fine. Use trusted websites. Use your head! You're in a sea filled with mines.
2. **An Anti-Virus:** Windows Defender is fine for the most part, but if you're a bit paranoid like me, and can sacrifice a little bit of system resources, use [Malwarebytes](https://www.malwarebytes.com/mwb-download) or [ESET](https://www.eset.com/us/download/home/?srsltid=AfmBOoogW1NG1yoXp_ura1JHB5wtyAugq9-mRwpqu-sReKgnlGygcw-f).
3. **An adblocker:** Frankly, it's just for convenience (and meh, *some* safety in case my common sense goes haywire). I don't want to find four popups of John Business showing me how I can get rich if I pay 4000$ to enroll into his course  just because I clicked on a random pixel of the website. Always use **Common Sense** anyway, because adblockers don't always adblock. [uBlock Origin](https://github.com/gorhill/uBlock) is good.
